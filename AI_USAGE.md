# AI Usage

I used AI assistance during the development of this project mainly to understand the assignment requirements, plan the project structure, and clarify some Python concepts.

The AI assistance was used for:

* Understanding the required scraping and ETL workflow.
* Planning the folder and file structure.
* Understanding how `requests.Session` and retry handling work.
* Getting guidance on BeautifulSoup selectors and pagination.
* Understanding data cleaning and validation approaches.
* Reviewing the deduplication logic.
* Identifying possible errors and improving the logging.
* Creating and reviewing test cases.
* Improving the README documentation.

The actual project was implemented and tested in my local VS Code environment. I also ran the scraper and verified the generated CSV, JSON report, and log files.

The final implementation was reviewed and adjusted based on the actual behavior of the application rather than directly relying on generated code.
